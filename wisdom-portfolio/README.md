# Wisdom Daniel Ukaegbu — Portfolio

A responsive single-page portfolio built with plain HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Before submitting
1. Add your own portrait as `images/profile.jpg`.
2. Add at least five genuine photos as `images/photo-1.jpg` through `images/photo-6.jpg`.
3. Verify the AI-platform description and update it to match the exact tasks/titles you held on Handshake AI, Outlier AI and Atlas AI.
4. Add your real GitHub and LinkedIn URLs if you want them displayed.
5. Test the page on mobile and desktop.
6. Publish the folder using GitHub Pages, Netlify or Vercel static hosting.

## Notes
- No framework, template, Bootstrap or Tailwind is used.
- The Google Fonts import requires an internet connection; system sans-serif fallback is available.
- Project artwork is created with CSS, not copied screenshots.
